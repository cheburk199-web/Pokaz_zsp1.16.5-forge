# Spawner Tooltip — Forge 1.16.5

Клиентский Forge-порт подсказки для пользовательских золотых спавнеров HolyWorld.

Показывает доступные в NBT данные: меч, чары, моба, счётчики и содержимое хранилища. Если сервер не передаёт эти данные клиенту, мод не сможет их восстановить.

## Сборка
GitHub Actions → Build Spawner Tooltip Forge 1.16.5 → Run workflow.

## Установка
Скачай artifact `spawner-tooltip-forge-1165` и положи JAR в папку `.minecraft/mods`. Запускай Forge 1.16.5.
